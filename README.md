# Project 1 — SIEM Monitoring & SOC Operational Readiness Validation Lab

# Description

Developed a Splunk-based SOC monitoring solution to detect, analyze, and visualize repeated failed authentication attempts across Windows systems.

The project focuses on centralized log analysis, authentication event monitoring, user and source-IP identification, detection of abnormal login patterns, and security dashboard development.

The solution provides SOC analysts with visibility into failed authentication activity and helps identify accounts or source IPs generating unusual numbers of login failures.

# Key SOC Skills

- Splunk SIEM
- SPL Query Development
- Windows Security Event Log Analysis
- Authentication Monitoring
- Failed Login Detection
- Source IP Analysis
- User Activity Analysis
- Security Dashboard Development
- Alert Configuration
- SOC Investigation
